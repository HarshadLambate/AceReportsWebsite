# Ace Reports

HTML test reports for .NET. Install one NuGet package and every `dotnet test` run
produces a single HTML report with logs, API calls, screenshots, retries and flaky-test detection.

**Website:** https://harshadlambate.github.io/AceReportsWebsite/  

**Live demo report:** https://harshadlambate.github.io/AceReportsWebsite/demo.html

| Framework | Install |
| --- | --- |
| xUnit v3 | `dotnet add package AceReports.Xunit` |
| NUnit | `dotnet add package AceReports.NUnit` |
| MSTest | `dotnet add package AceReports.MSTest` |
| Reqnroll | `dotnet add package AceReports.Reqnroll` |
